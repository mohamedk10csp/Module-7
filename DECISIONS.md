#Design Decisions 

I renamed functions & variables for readability. For example, I changed 'do_math_stuff' to 'process_numbers' and 'do_string-stuff' to 'process_strings'. I also changed 'list1' to numbers and 'list2' to strings. When changes are made to the code, an explanation of what each part of the code is doing can be provided, which helps explain what the code does without having to read through the entire program. 

List comprehensions were used, rather than loops, to shorten and improve the readability of the code. All calculations and string processing are the same as before. I made sure I could duplicate the output of the original program by trying it in VS Code with the updated script. 

I  also added docstrings which will provide an explanation of each function including its parameters and return value. I added comments to my code to explain the logic of processing the code. These changes make the code easier to read and maintain, as other developers can more easily understand it in the future and make changes.
